
# 🧠 Interactive Quiz App

An interactive multiple-choice quiz application built using HTML, CSS, and JavaScript. Test your knowledge, receive instant feedback, and track your final score.

## ✨ Features

- 10 multiple-choice questions.
- Instant feedback for correct and incorrect answers.
- 15-second countdown timer for each question.
- Automatic handling of unanswered questions.
- Live progress bar.
- Automatic score and accuracy calculation.
- Results screen with performance messages.
- Restart quiz functionality.
- Responsive design for mobile and desktop.
- No external API or libraries required.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Click **Start Quiz**.
5. Select an answer before the timer expires.
6. View your final score after all questions.
7. Click **Play Again** to restart.

## 🎮 How to Play

- Each question has four answer options.
- Each question has a 15-second time limit.
- Correct answers earn one point.
- Incorrect or unanswered questions earn zero points.
- Instant feedback displays the correct answer.
- Your final score and accuracy appear at the end.

## 🌐 Deploy on GitHub Pages

1. Upload all four files to your GitHub repository.
2. Open Settings → Pages.
3. Select Deploy from a branch.
4. Choose the `main` branch and `/ (root)`.
5. Click Save.
6. Visit the published GitHub Pages URL.
